# CuentaConmigo

Auditoría ciudadana, comunitaria y no partidaria de las elecciones argentinas de 2027.

- **Telegramas**: fiscales y autoridades de mesa fotografían el telegrama de escrutinio;
  las fotos se procesan de forma centralizada y se cotejan con los resultados oficiales.
- **Desinformación**: una red de voluntarios detecta, verifica y responde con fuentes,
  en tiempo real, las noticias falsas virales sobre el proceso electoral.

Estado: idea / investigación. Ver [docs/hackdash.md](docs/hackdash.md) para la ficha
del proyecto y [AGENTS.md](AGENTS.md) para las reglas de trabajo.
