# Bounded task contract

- ID / role / owner:
- Tool / effective model (none for executor):
- Single objective / SPEC and criteria:
- Base commit / input revisions:
- Authorized read paths:
- Exclusive write paths (none for read-only roles):
- Constraints / unresolved architecture or installation decisions:
- Dependencies / existing evidence / unchanged inputs:
- Acceptance / authorized verification commands:
- Model or resource budget, if additional inference was explicitly authorized:
- Stop conditions:
- State / results / exit codes / artifact references:
- Reviewer identity / reviewed revision / review status:
- Handoff / remaining work:

This contract describes task scope. The actual runner must enforce access.
Do not treat a role, budget placeholder or active-agent limit as permission to
invoke another model, install tools or change architecture.
