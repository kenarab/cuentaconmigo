# Ícono de CuentaConmigo

Concepto: **"cuenta conmigo"** como juego entre *contar* (votos) y *contar con*
(acción cooperativa). Cuatro palotes de conteo que también son personas (cabeza y
cuerpo) se cierran con la quinta marca diagonal: la persona que se suma y completa
el conteo. Auditar juntos.

- Fondo: degradé celeste → azul. Colores nacionales, no partidarios.
- Personas/palotes: blanco. Quinta marca: dorado Sol de Mayo `#F6B40E`.
- Sin texto, legible a 60 px. Esquinas cuadradas: iOS/Android aplican su máscara.

Regenerar (sin dependencias, sólo Swift en macOS):

```sh
swift design/icon/render-icon.swift design/icon/AppIcon-1024.png
```
